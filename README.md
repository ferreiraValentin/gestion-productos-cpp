#🧩 Sistema de Gestión de Productos (C++)
Proyecto personal desarrollado para practicar programación estructurada en C++ utilizando arrays, funciones, estructuras y archivos binarios.

##🚀 Funcionalidades
Alta de productos

Listado completo

Búsqueda por código

Modificación de precio

Baja lógica

Guardado en archivo binario (productos.dat)

Carga desde archivo binario

Menú interactivo

##🧱 Tecnologías utilizadas
C++

Archivos binarios (fwrite, fread)

Programación estructurada

Visual Studio Code / CodeBlocks

##📂 Estructura del proyecto
/gestion-productos-cpp
├── main.cpp
├── funciones.cpp (si aplica)
├── funciones.h (si aplica)
├── productos.dat (archivo generado por el programa)
└── README.md

##▶️ Ejecución
Compilar con cualquier IDE o desde terminal:
g++ main.cpp -o gestion
./gestion
